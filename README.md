# Flor-Es

Voorbeeldwebsite van bloemiste Flor-Es: gewone HTML, CSS en JavaScript, zonder build-stap.

Pagina's: `index.html`, `workshops.html`, `groei-en-bloei.html`, `bloemwerk.html`, `contact.html`.

Foto's, prijzen, referenties en contactgegevens zijn nog plaatshouders. Het contactformulier verstuurt nog niets.
